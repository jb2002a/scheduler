# M1·M3 토큰과 소요 시간

2026-11-18 실행이다. 모델은 `gpt-5.6-luna`, 시나리오는 S1–S10, 크기 100·300·500, 반복 5회다. 시나리오 실행은 양쪽 모두 150회이고, 모델 호출은 195회다. S1–S8은 1회, S9는 2회, S10은 3회 호출한다. 크기마다 65회다.

M1은 카탈로그를 시스템 프롬프트에 넣고 시간표 JSON을 직접 받는다. M3는 짧은 지시와 `schedule` 도구만 주고, 시간표는 솔버가 만든다. 채점 차이는 `M1_RESULTS.md`와 `MILESTONES.md`에 있다. 이 문서는 토큰과 시간만 다룬다.

원문:

- M1: `experiments/baseline/results/gpt-5.6-luna.jsonl`
- M3: `experiments/solver_compare/results/gpt-5.6-luna.jsonl`

## 세는 방법

시간은 결과 JSONL의 `elapsed_ms`다. 시나리오 한 번의 벽시계라서 S9·S10의 여러 턴이 들어 있다. M3에는 그 안의 솔버 실행도 포함된다. 실험은 호출을 순서대로 돌렸고, 위 합계는 그 대기 시간을 더한 것이다.

토큰은 API `usage`가 저장되지 않아, 프롬프트와 응답 본문을 `tiktoken`의 `o200k_base`로 다시 센 값이다. 메시지 역할에 붙는 고정 토큰은 넣지 않았다. 금액 단가는 프로젝트에 없다.

M3는 턴마다 `raw_arguments`와 조건 JSON이 남아 있다. 실패로 빠지기 전에 끊긴 호출은 0이라, 195회를 그대로 다시 세었다. 입력은 코드가 보낸 시스템 지시, 사용자 문장, 이전 조건 JSON, 도구 스키마다.

M1은 마지막 응답만 저장된다. S9·S10의 중간 응답은 같은 실행의 마지막 응답 길이로 넣었다. 중간 응답을 빼면 입력 1,058,135, 출력 41,686, 합계 1,099,821이다. 위 표와의 차이는 35,459토큰으로, M1 합계의 3%다. 응답 본문에 없는 reasoning 토큰이 과금됐다면 이 숫자에는 없다.
