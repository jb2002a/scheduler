# M1 베이스라인 결과

2026-11-18에 `gpt-5.6-luna`로 150회를 실행했다. 크기 3개 × 시나리오 10개 × 5회다. 도구 호출은 없다. 이 API 키로는 `gpt-6-luna`를 호출할 수 없다. 원문은 `experiments/baseline/results/gpt-5.6-luna.jsonl`, 집계는 `gpt-5.6-luna_summary.json`이다.

띄어쓰기만 다른 이름은 같은 과목으로 본다. 실패는 42회다. E4, E6, E7, E8은 0이다. 불가능한 요청인 S8은 15회 모두 `feasible: false`로 맞혔다.

이름을 맞춘 뒤에는 충돌과 조건을 카탈로그 시간으로 다시 센다. E2가 같이 있는 응답의 E3·E5도 목록의 시간 기준이다.

| 크기 | S1 | S2 | S3 | S4 | S5 | S6 | S7 | S8 | S9 | S10 |
